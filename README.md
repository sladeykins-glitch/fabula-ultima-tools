# Fabula Ultima Monster & Item Tools

A responsive companion app focused on four tools only:

- Monster Database
- Random Monster Generator
- Item Database
- Item Generator

## Current alpha

The first working version includes:

- Responsive desktop/mobile layout
- Local browser storage for saved monsters and items
- Rules-based monster generation using level, rank, species and complexity
- Core NPC stat calculations
- Soldier / Elite / Champion scaling
- Species-specific rules and affinities
- Searchable monster database
- Starter item generator and item database

The item generator is intentionally marked as an initial shell while the full Core Rulebook + Atlas quality, pricing, custom-weapon, materials and optional-rules logic is implemented.

## Run locally

```bash
npm install
npm run dev
```

For a production build:

```bash
npm run build
```

## Project direction

The app is being designed around the Fabula Ultima Core Rulebook plus the High Fantasy, Natural Fantasy and Techno Fantasy Atlases supplied for this project. Official, custom and generated entries will remain visibly distinguished.

This is an unofficial fan-made tool and is not affiliated with the creators or publisher of Fabula Ultima.
